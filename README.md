# trekking-management-system-may2026-mad1
This is may 2026 term MAD1 project, wherein an efficient system to manage trekking activities involving trek organizers, staff, and participants is built. Currently, many trekking groups rely on spreadsheets, phone calls, or manual coordination, which makes it difficult to manage trek approvals, track bookings, avoid overbooking, and maintain trek history.
Therefore, this is Trekking Management Application web application that allows Admin, Trek Staff, and Users (Trekkers) to interact with the system based on their roles.
